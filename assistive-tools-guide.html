Assistive Learning Tools

Choose the reading and interaction options that work for you. You do not need to tell us why.

1. Read larger text

Use the A+ and A− buttons above. This setting is remembered on your device for the Clear Start and practice pages.

2. Use a screen reader

Explore your device's built-in accessibility settings. Keyboard users can use Tab to move between controls. Compatibility with different screen readers still needs independent testing.

3. Practice with your voice

Some devices support dictation in text fields. Use fictional examples only, and review the words afterward. This page does not request microphone access.
