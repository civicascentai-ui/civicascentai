# Safari Restraint Rule

## Status
FIXED AND ACTIVE

## Core Principle
**Rich world. Simple attention. Controlled motion. One dominant story.**

The previous rigid restraint rules are superseded by this refined system.

## Revised Rules

### 1. Motion systems
Old rule: Five active motion systems maximum.

New rule: **Five dominant motion systems maximum.**
Subtle micro-motion is allowed when it does not perceptually compete for attention.

### 2. Wildlife activity
Old rule: One wildlife event at a time.

New rule: **One dominant wildlife event at a time.**
Secondary distant wildlife may exist naturally as environmental life.

### 3. Camera movement
Old rule: Minimal camera movement.

New rule: **Camera movement must be purposeful and nearly invisible.**
Slow cinematic drift, push, parallax, or breathing movement is allowed when it strengthens immersion without calling attention to the camera itself.

### 4. Wildlife density
Old rule: Limited wildlife density.

New rule: **Visual hierarchy controls density.**
A distant herd, birds, or subtle background life is acceptable if it reads as atmosphere rather than a competing focal event.

### 5. Simplicity
Simplicity does not mean emptiness.

The environment may be visually rich, detailed, layered, and sophisticated while keeping the user's attention simple and clear.

## Rules Preserved Without Change
- Senior/beginner simplicity
- Reduced-motion compatibility
- No known defect before moving forward
- No brochure/card treatment
- Art-first; React remains a support layer
- No production deployment before visual proof
- Safari Learning World remains the only active concept direction
- No UI during the base living-canvas proof unless explicitly approved later

## Evaluation Test
Before accepting any addition, ask:
1. Does it make the world feel more alive?
2. Does it create a new competing focal point?
3. Does it strengthen depth, realism, atmosphere, or story?
4. Would removing it make the scene stronger?
5. Does it preserve calm clarity for seniors and first-time AI users?

If an addition enriches the world without fragmenting attention, it is allowed.

## Team Rule
Agents 1–4 and QC oversight must use this revised restraint framework for all Safari work going forward.
