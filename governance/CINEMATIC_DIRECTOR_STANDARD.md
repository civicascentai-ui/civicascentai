# CivicAscent AI — Cinematic Director Standard

Status: ACTIVE CREATIVE DIRECTION
Date: 2026-09-29
Benchmark: OpenArt Director-style short-film production planning.

## Owner Direction

CivicAscent AI must feel like a directed short film, not a conventional animated website.

Each major experience must be planned as a film scene using:
- environment reference
- storyboard
- shot list
- camera movement
- lighting and mood
- motion layers
- sound/voice intent
- interactive story beats
- scene transitions
- accessibility behavior
- mobile framing
- obvious next action

## Prototype 09 Safari Standard

The Safari Learning World remains the active theme.

Required qualities:
- premium living African safari environment
- elevated lodge/terrace viewpoint
- elephants at the watering hole as the dominant living event
- secondary wildlife and environmental movement
- cinematic depth, haze, light, reflections, and foreground framing
- minimal interface chrome
- interactions integrated into the environment
- simple enough for someone new to AI

Avoid:
- brochure layouts
- card grids
- generic hero sections
- static informational pages
- game-like UI
- random animation
- cluttered overlays

## Scene Production Gate

Before engineering a major scene, Agent 1 must define:

1. scene purpose
2. user outcome
3. focal event
4. environment reference
5. storyboard
6. camera plan
7. lighting plan
8. motion plan
9. interaction points
10. voice/audio intent
11. accessibility notes
12. mobile framing
13. transition in
14. transition out
15. next action
16. reduced-motion behavior

No scene advances without this production board.

## Agent Review

Agent 1: cinematic direction and storyboard.
Agent 2: engineering, performance, responsive behavior.
Agent 3: accessibility, navigation, keyboard/touch, reduced motion.
Agent 4: cinematic quality, shot continuity, lighting, media quality.
Agent 5: tool capability, cost, licensing, duplication, availability.
Agent 6: learning value, business value, trust, conversion.
