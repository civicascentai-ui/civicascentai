# React Operating Rule

## Status
APPROVED AND ACTIVE

React is approved as the application structure layer for CivicAscent AI.

## Role
React is responsible for future application state, navigation, accessibility controls, language state, learning-area state, and reusable interface behavior.

React is **not** the visual centerpiece. The Safari living canvas remains art-first.

## Architecture
- React — application shell and state
- Three.js / React Three Fiber — future spatial and WebGL behavior when justified
- AI-generated cinematic media — environmental source material
- GitHub Actions — automated checks
- Harness + Opus — specialist engineering capability
- Agent 3 — independent QA and accessibility
- Agent 4 — continuous separate critical evaluation
- ChatGPT — QC / Governance Overseer

## Safari Rule
The Safari prototype is isolated under `prototype-react/` until the visual direction and motion prototype are approved.

Do not replace production files merely because React has been introduced.

## Restraint Rule
Do not componentize or animate elements without a clear product reason. React should reduce complexity, not create it.
