# CivicAscent AI: Creative and Documentation Workstream SOP

Effective: 2026-10-12 | Status: Adopted operating instructions; runtime agent wiring not yet verified | Cost ceiling: $0 incremental spend

## Responsibilities
- **Creative / Scout research:** Identify available zero-cost features and reputable official documentation for the Craft series. Draft design concepts, flyers, brand assets, and course visuals only using verified capabilities. Do not claim an app has been connected or run without proof.
- **Documentation / Sam coordination:** Use ONLYOFFICE Documents on the owner's Android phone for drafting, reviewing, and saving DOCX; use spreadsheets (XLSX), presentations (PPTX), and PDF only within verified capabilities. Maintain templates, revision control and customer-facing disclaimer checks.
- **CODI operations:** Route requests to the appropriate workstream, enforce budget and privacy boundaries, collect artifacts and evidence, and escalate blocked tool access.
- **Friday / QC:** Independently verify opening, editing, save/reopen, formatting, PDF fidelity, accessibility and output disclaimers before any customer-facing release. Log results with screenshot or test artifact. No self-approval.

## Intake and routing
1. Classify request as **creative** (logo, flyer, image, vector) or **office** (workbook, proposal, spreadsheet, presentation, PDF).
2. Check inventory at `docs/library/creative-and-office-tools.md` and the actual available connected tool capability. Do not equate listed inventory with installed/connected automation.
3. Produce editable source and export format when feasible; name files consistently (`CivicAscent_<Project>_<Asset>_vN`).
4. Validate actual output against intended use; record QC pass/fail with evidence and limitations.
5. Only then mark ready for internal use. Customer-facing release needs privacy, accessibility, disclaimer and independent QC review.

## Tool status and handoff
- ONLYOFFICE Android: owner installed; sample DOCX open/edit/save/reopen tested (reopen user-confirmed); XLSX/PPTX sample opening user-confirmed; sample PDF rendering screenshot-confirmed. CivicAscent actual workbook fidelity not yet tested.
- ArtCraft / Craft series: owner says already added. Specific Craft app installation, integration, feature availability and QC are not verified. Creative workstream must establish those before claiming production use.
- No new paid accounts, cloud server, automatic renewal or auto-refill. Local files preferred. Signed PDFs remain untouched.
- No access to the owner's phone filesystem through this SOP. Owner must open/share a file when local-only.

## Acceptance checklist
- [ ] Craft feature inventory and licensing verified from official sources
- [ ] One non-sensitive branded flyer generated and QC reviewed
- [ ] CivicAscent Veterans workbook opened and visually inspected in ONLYOFFICE Android
- [ ] DOCX export/reopen and formatting verified
- [ ] XLSX editing and save/reopen verified
- [ ] PPTX editing and save/reopen verified
- [ ] PDF annotations/forms tested separately without changing signed originals
- [ ] All outward-facing disclaimers and accessibility review passed
- [ ] Real agent/runtime assignments acknowledged; do not imply autonomous agents are running until verified
