# CivicAscent AI | Independent Course Kit QC Checklist

**Review target:** `docs/qa-course-kit-content-draft.md` (QA only)

**Current result: NOT APPROVED.** This is a review protocol, not a claim that independent reviewers have performed checks.

## Curriculum and learner experience

- [ ] Verify each of the four lesson objectives is teachable within the stated session duration.
- [ ] Pilot each exercise with a first-time learner using fictional information only.
- [ ] Confirm plain-language instructions, realistic completion criteria, and instructor fallback steps.
- [ ] Check factual claims and external references against reliable primary sources.
- [ ] Confirm print-friendly handouts and no forced account creation for observing a session.

## Accessibility and inclusion

- [ ] Verify logical heading order, readable contrast, and keyboard-only navigation in final delivery format.
- [ ] Test screen-reader reading order, meaningful link text, and text alternatives for all final images.
- [ ] Review large-print legibility and mobile scaling without horizontal scrolling.
- [ ] Arrange qualified ASL or Deaf-community feedback before claiming ASL support.
- [ ] Validate translated Spanish content with a proficient human reviewer before describing it as bilingual-ready.
- [ ] Ask veteran-community reviewers to check respectful, accurate language; do not imply VA endorsement.

## Security, payments and delivery

- [ ] Verify the final ZIP contents contain only approved learner assets and no credentials or personal information.
- [ ] Check copyright/licensing for images, examples, and third-party materials.
- [ ] Stage approved ZIP objects in a nonpublic QA storage bucket; verify object paths and checksums.
- [ ] Confirm payment grants access only from authenticated, signed TEST webhook events.
- [ ] Confirm unpaid, refunded, disputed and mismatched-identity cases fail closed.
- [ ] Verify no customer ZIP link is publicly reusable; confirm private downloads and receipt reconciliation.
- [ ] Record 25 distinct complete sandbox E2E cases with independent evidence.

## Evidence record

For each item record: reviewer identity/role, date, test environment, exact artifact version, pass/fail, evidence link, defects, remediation, and independent retest. A self-authored checklist is not independent QC evidence.
