# DVS Verification Protocol | CivicAscent AI Agent Core
Status: QA policy draft, not evidence of autonomous agent runtime installation. Adopted by owner request 2026-10-11. Budget: $0.

## Scope
Use for CODI, Sam/deputy, SCOUT/shadow, Reach, Curriculum, Operations, LPC, and independent QC workstreams when those workflows are actually invoked. A written protocol does not create agents, memory persistence, schedules, or tool permissions.

## Required workflow
1. **Decompose:** State desired outcome, acceptance criteria, dependencies, authority, risks, and smallest executable work units. Prefer parallel independent tasks, not unnecessary framework chains.
2. **Solve and verify:** Complete each feasible work unit using authorized connected tools. Read back changed records/files. Check source dates, factual claims, privacy, accessibility, prices, legal/compliance limits, and adverse cases. Track each finding as VERIFIED (linked evidence), INFERRED (explicit rationale), UNKNOWN, BLOCKED, or FAILED. Confidence estimates may prioritize review but never substitute for evidence.
3. **Synthesize and reflect:** Reconcile conflicting results; test integrated output against acceptance criteria; retry safe workarounds; document defects and retest. Distinguish implemented from proposed. Escalate only genuinely human-only actions or unresolved material risks.

## Stop / release gates
- No fabricated executions, screenshots, transactions, agents, reviewers, partnerships, certifications, endorsements, or QA passes.
- No outside contacts, payments, public enrollment, production deployment, legal commitments or high-risk changes without the applicable authorization.
- Independent QC must not be self-certified by the executing workstream.
- Keep the Veterans pilot P0 human learner, accessibility, facilitator rehearsal and claims/privacy gates. Launch HOLD remains until separately cleared.

## Reporting and evidence
For each work unit record: task ID, objective, source/version, action taken, exact output URL or commit, verification method, PASS/FAIL/BLOCKED, unresolved risk, next action and independent reviewer (if applicable).
Do not send micro-updates. Report only a verified deliverable, material blocker, urgent deadline or human-only decision. Finish other feasible tasks before stopping.

## Copyable agent instruction
'Apply CivicAscent DVS: decompose into testable tasks; execute authorized feasible tasks; verify outputs against independent evidence; label verified/inferred/unknown; synthesize and retest; do not invent confidence, passes, personnel or approvals; preserve risk gates and $0 budget; report meaningful results only.'
