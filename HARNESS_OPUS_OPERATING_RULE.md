# Harness + Opus Operating Rule

## Status
APPROVED AND ACTIVE

## Purpose
CivicAscent AI may use a Harness-based engineering layer with Claude Opus as a specialist engineering and reasoning capability.

Opus is **not** a new management agent and does not replace the authority of Agents 1–4 or ChatGPT QC governance.

## Team Structure
- Agent 1 — Experience Director
- Agent 2 — Lead Production Engineer
- Harness Engineering Layer — specialist tools and model access
  - Claude Opus specialist
  - GitHub
  - browser/testing
  - deployment tools
  - future WebGL/media tooling
- Agent 3 — Quality & Accessibility Director
- Agent 4 — Critical Evaluation Director
- ChatGPT — QC / Governance Overseer

## Opus Role
Opus may be invoked for:
- difficult architecture decisions
- complex debugging
- code review
- root-cause analysis
- hidden regression detection
- alternative implementation proposals
- performance analysis
- WebGL / Three.js architecture review
- accessibility implementation review
- deployment architecture review
- second-opinion engineering analysis

## Authority Boundaries
- Agent 1 retains ownership of experience and creative direction.
- Agent 2 retains ownership of engineering implementation.
- Opus does not automatically redesign the Safari experience.
- Opus does not overrule Agent 1, Agent 2, Agent 3, Agent 4, or QC governance.
- Agent 3 remains independent QA.
- Agent 4 remains in a constant independent evaluation loop and reports separately.
- QC governance resolves conflicts and protects core rules.

## Required Workflow
Primary owner → specialist consultation → owner integrates → independent QA → Agent 4 evaluation → QC oversight

## Anti-Chaos Rule
Do not create a chain where multiple models repeatedly overwrite one another's work.

Avoid:
GPT changes → Opus changes → another agent changes → Agent 2 changes again

Use:
Owner defines → Opus advises → owner integrates → QA validates

## Safari Application
For the Safari Learning World, Opus should be used primarily after the living-canvas prototype proves the visual direction and the project enters deeper engineering involving:
- AI video integration
- WebGL
- layered environmental motion
- responsive rendering
- mobile performance
- reduced-motion accessibility
- interaction architecture

## Standing Rule
Harness + Opus is an approved specialist engineering capability for CivicAscent AI going forward.
