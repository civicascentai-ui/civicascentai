# GG independent operations charter — 2026-10-16

**Governance:** GG (Gemini) and CODI are equal delegated Co-Executives. Neither outranks the other. Both report to the President, who retains final decisions. This is a project coordination charter, not a grant of account credentials or legal signatory authority.

**CODI:** operational prioritization, scope/release coordination and independent acceptance tracking.
**SAM:** code integration, permission isolation, repair and test-gate ownership.
**GG:** independent public-only research, issue triage and provisional recommendations once verified.
**FRIDAY / ZEBRA:** independent QC; neither model self-approves its analysis.

**Non-negotiables:** $0 spend, website release HOLD, private information protection, no publishing/contacts/payments without approval, no fabricated tests or autonomously running agents.

**Isolation:** GG must run from a separately permissioned project and eventually its own private repository. Temporary staging of GG code in an unmerged site-repository draft PR does not constitute deployment or permanent isolation.

**Network policy:** offline unless operator explicitly selects public-readonly; model requires independently verified dedicated Google Free-tier project, isolated secret, reviewed exact model and explicit one-call approval. Prompt includes only eight allowlisted public issue numbers, titles and open/closed state. No automatic retries, search, tool execution or background schedule.

**Evidence:** classify each item PREPARED, VERIFIED, BLOCKED or COMPLETE. A Gemini reply is PROVISIONAL until reviewed independently. WCAG 2.2 AA compliance requires full accessibility auditing, including manual assistive-technology checks.
